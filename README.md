# EventStore

Your smart event planner.

## Опис

EventStore — це настільний кросплатформний застосунок для планування подій, який допомагає користувачу сформувати деталізований план заходу відповідно до його побажань, обраного стилю та бюджету, автоматизувати кошторис і відстежувати готовність підготовки.

## Основні можливості

- **Керування подіями**: створення, редагування параметрів, перегляд та видалення запланованих подій.
- **Автоматична генерація плану**: персоналізований підбір компонентів і завдань (локація, кейтеринг, музика, фото, декор) на основі введених параметрів.
- **Розподіл та контроль бюджету**: автоматичний прорахунок планових витрат за категоріями послуг та зіставлення із загальним бюджетом.
- **Інтерактивний чекліст**: керування життєвим циклом завдань і динамічний перерахунок прогресу готовності події.

## Технології

- **Мова програмування**: C# (.NET 8)
- **Користувацький інтерфейс**: Avalonia UI (XAML, патерн MVVM, CommunityToolkit.Mvvm)
- **Архітектура**: Багатошарова (Avalonia UI / BLL / DAL)
- **База даних**: PostgreSQL
- **Контроль версій та проєктний менеджмент**: Git, GitHub
