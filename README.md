# EventStore

**Your smart event planner.**

## Опис

EventStore — це вебзастосунок для планування подій,
який допомагає користувачу створити персоналізований
план відповідно до його побажань та бюджету.

## Основні можливості

- Створення події
- Персональні рекомендації
- Розрахунок бюджету
- Оптимізація витрат
- Формування готового плану події
- Створення запрошення
